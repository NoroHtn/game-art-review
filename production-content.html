05 / PRODUCTION

A clear path from concept to handoff.

A proposed 20-working-day art production cycle, including two days of contingency. UI, illustration and animation run in parallel after their dependencies are approved.

Team and workload

Planning estimates for Crash Game only, starting from the submitted visual direction. One UI Designer, one 2D Artist and one Spine Animator, with part-time Art Lead support. Assume consolidated review feedback within one working day. The Instant Game plan is a separate allocation; the same team is not committed to both concurrently.

41 estimated person-days distributed across 20 working days. Base effort excludes unspent contingency; any extra effort uses the reserved capacity and is tracked separately. Re-estimate after the first rig and mobile review.

A frontend engineer must be available separately for prototype integration and state testing. Confirm that dependency at kickoff; without it, delivery is an integration-ready art package. Engineering implementation, game mathematics, audio, certification and release are outside this estimate.

Planned handoff acceptance

Named source assets and exports; documented dimensions and pivots; a separated layer inventory; the agreed control-state library; motion timings and reduced-motion behavior; a Figma presentation and matching PDF with working access.

The website and linked presentations document the submitted visual direction and interaction proposals. Production rigging, animation exports and runtime integration remain planned work.
