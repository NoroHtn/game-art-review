# Pirate Sea Hop visual preview

The UI starts from the 12ui desktop console export, with the mobile export used for responsive hierarchy. `design-provenance.json` records the source conversions. World art is composed from separate image assets under `/assets/instant/`; multiplier text is live HTML.

`preview-state.js` contains a scripted presentation state machine using integer cents. It is not game math, a wagering API, or a wallet. Six supplied multiplier values are a visual fixture and do not define the production maximum. Difficulty is presentation-only; GO MAX awaits the original behavior specification.

`game.js` handles input, state changes and review scenarios. `game.css` defines layout and temporary raster-transform animations. The review inspector uses same-origin messages; direct `?state=ready|jump|active|cashout|sink|shark|tentacle|funds|reconnecting` links are also supported.

Temporary hero J1 remains unapproved. Preserve the clean back, anatomical left hook and right peg. Final articulated animation, character selection, source rules, native Figma presentation and matching submission PDF remain open.
