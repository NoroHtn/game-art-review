# Game Art Review — current redesign

## Purpose and source

The site is an evidence index for art directors and art leads, not a marketing landing page. Sources: supplied Game Art Lead Test Assignment PDF, approved project artwork, and the user's latest references. The assignment asks for concept, theme, audience, visual direction, principles, differentiation, a moodboard, main screen, production breakdown, milestones, role workload, timeline, risks, Figma and PDF.

The earlier design-review.md records v7, not this implementation.

## Changes

- Neutral white/graphite shell, restrained blue selection, self-hosted Nunito Sans.
- Working title MOO-NAPPED!; company name removed from page branding, site title and URL label.
- Visible ten-section navigation and direct desktop, mobile, inventory and specification links.
- Seven assignment requirements mapped to evidence. Labels mean availability, never a self-awarded evaluation score.
- Separate Instant route with the same structure and nine asset-pending categories. No Crash art or mechanics are claimed as Instant work. No upload backend.
- Six supplied references in upload order, full uncropped compositions and visible signatures. Reversible CSS monochrome/soft-contrast treatment harmonizes display; Originals restores supplied colors. Original files are unchanged. Reference authorship is not claimed.
- Licensed Caprasimo live multiplier with dark outline and short shadow: a stylistic match, not exact identification of the raster reference font.
- Persisted color/grayscale control changes presentation only; it does not reset the game.
- Refreshed desktop and mobile game captures.
- Existing scenarios, independent bet settlement, five-second timeline, original asset routes, state library and production documentation retained.

## 12ui integration

Four root candidates were generated; A was inspected and selected. Completed responsive HTML/LayerDoc established the numbered sidebar, preview/evidence split, surfaces, typography and thumbnail row. Existing factual artwork replaces generated reinterpretations. The extracted orbit mark and declared SVG icons are used as files.

Branch execution generated and converted Instant. The reference-page image failed with a provider error; its board uses the selected shared card language and six real user files. Prototype assembly stopped at a missing local Chromium dependency. QA uses the supported cloud browser, not another browser installed to bypass that constraint. Completed root/Instant exports were adapted to existing routes and game behavior.

Intentional corrections: remove literal “Persistent Crash / Instant switch” instructions; implement a real switch; remove Crash imagery from Instant; substitute seven actual assignment requirements for generated checkmarks; keep Figma/PDF pending; preserve approved art; enlarge small text and allow natural wrapping. Mobile retains all navigation and provides a return-to-sections link.

Screenshot closeouts use the unchanged original root LayerDoc and Instant screen's original conversion-derived LayerDoc. Both are unanchored specifications, not numerical DOM fidelity scores. Original targets and rendered pages were compared visually. No imagery was purchased for closeout. The gallery has no generated approved target because that branch failed.
