Demo controls

Bet before the round starts. Cash out while live. Each position is independent. Returns include the original stake.

Started rounds progress automatically and crash randomly between 1.00x and 5.00x. The crash stays visible until replay. This prototype does not implement game math, a wallet or network arbitration.
